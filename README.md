# WeGuardian 2.4 Decompiled Source

This repository contains a reconstructed Maven project decompiled from `weguardian-2.4.jar`.

## Build

```bash
mvn package
```

The shaded plugin JAR is produced at:

```text
target/weguardian-2.4.jar
```

## Notes

- Decompiled with CFR 0.152.
- The original Maven `pom.xml` and plugin resources were recovered from the JAR metadata.
- Third-party shaded libraries were restored as Maven dependencies instead of committing decompiled dependency sources.
- No upstream license file was recovered for the plugin source.
